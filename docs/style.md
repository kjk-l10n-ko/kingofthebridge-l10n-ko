# 말투
- 게임: 체스를 두며 다리 밑 트롤과 규칙을 두고 다투는 코미디. 트롤(TrollDialogTable)은 능글맞고 장난스러운 반말~하오체 섞인 말투, 플레이어에게 다리를 못 건너게 협박조.
- 메뉴/UI(MenuTable, OverworldTable, ChessTable): 짧은 명사형, 영어 대문자 라벨은 한국어 그대로 간결하게.
- RuleBreakTable: 문장 조각("did not catch the other cheating?")이므로 앞 문맥 "규칙 위반:" 뒤에 붙는 형태로 번역.
- {selectedOption}, [ SPACE ] 등 자리표시자/키 표기는 그대로 유지.
