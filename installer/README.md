# King of the Bridge 한글 패치 (v1.024) (2026-11-17)

게임 **King of the Bridge**(Steam, v1.024)의 비공식 한글 패치입니다.

* 검수: 김작가
* 작업/번역: Claude Sonnet 5.5/Deepseek v4 flash
* 오류, 오타는 kimjakka96@gmail.com로 제보해주시면 수정 배포하도록 하겠습니다.

## 설정 방법

설치 후 게임을 실행하고 `설정 > 텍스트 > 언어`에서 **한국어**를 선택함. 한 번 선택하면 설정이 저장됨.

## 패치 내용

* 게임 UI·트롤 대사·크레딧 327개 문자열 번역
* 규칙서 42쪽과 목차 항목의 그림 속 글자를 한글 손글씨로 교체
* Steam 업적 37개의 이름과 설명을 한글로 표시 (게임 코드 `Assembly-CSharp.dll`에 변경분만 적용)
* 픽셀 폰트 Galmuri11 Bold 적용
* 게임에 한국어 로케일이 없어 네덜란드어 슬롯을 한국어로 대체함. 타이틀 로고는 그림 파일이라 원문 그대로 유지됨.

게임 파일은 포함되어 있지 않으며, 사용자의 원본 파일에 변경분만 적용함. 원본 파일은 게임 폴더의 `kor_bak` 폴더에 백업됨.
